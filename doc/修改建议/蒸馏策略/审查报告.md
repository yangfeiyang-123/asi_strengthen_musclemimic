# d0a32c9 蒸馏策略实现审查报告

审查对象：`origin/main = d0a32c9dec4bdf3c9ff0c6fa159dd6021523d1b7` 这一版仓库。

审查目标：判断当前仓库是否已经满足“只针对 ForehandClear / MyoFullBody 动作轨迹完成，不考虑球拍击球”的 **no-future-lookahead student policy 蒸馏方案**要求；如果没有满足，给出后续需要修改的内容。

> 重要说明：本报告基于该提交下可读取的关键文件、已发现的新增 `musclemimic/distill/` 模块、PPO / env wrapper / ForehandClear 配置进行静态审查；没有在远端机器上实际运行训练、测试或 benchmark。

## 1. 总体结论

当前 `d0a32c9` **已经完成了蒸馏方案的第一层基础设施**，主要包括：

1. 新增了 `musclemimic/distill/obs_filter.py`，可以把 teacher 的完整 observation 过滤成 student observation。
2. 新增了 `musclemimic/distill/dataset.py`，可以保存 / 加载 NPZ shard 形式的蒸馏数据。
3. `wrap_env()` 中已经接入了 `StudentObservationFilterWrapper`，并且保证它在 `NStepWrapper` 之前执行。
4. `PPOJax._create_network()` 也已经在创建网络维度时考虑 `student_obs_filter`。
5. 新增了 `test_student_obs_filter.py` 和 `test_distill_dataset.py`，覆盖了 student observation filter 和 distillation shard IO 的基础行为。

但是，当前版本**还没有形成完整可执行的 teacher → student 蒸馏训练闭环**。它更像是：

```text
已完成：student observation filter + distillation dataset IO 基础模块
未完成：teacher rollout 采集器 + BC/KD 训练器 + student PPO fine-tune 配置 + DAgger/on-policy correction + 完整评估流水线
```

因此，当前版本可以判定为：

```text
Milestone 1: student observation / dataset foundation —— 基本满足
Milestone 2: off-policy BC/KD distillation —— 未满足
Milestone 3: on-policy correction / student PPO fine-tune —— 未满足
Milestone 4: teacher-vs-student acceptance evaluation —— 未满足
```

## 2. 当前已满足的部分

### 2.1 Teacher PPO 轨迹模仿训练基础仍然存在

当前 ForehandClear teacher 训练配置仍然合理：

```yaml
experiment:
  env_params:
    env_name: MjxMyoFullBody
    num_envs: 256
    disable_fingers: true

  task_factory:
    params:
      amass_dataset_conf:
        rel_dataset_path:
          - badminton/train/forehand_clear_clip1_merged_poses
          - badminton/train/forehand_clear_clip2_merged_poses
          - badminton/train/forehand_clear_clip3_merged_poses
        retargeting_method: gmr
```

这说明当前 teacher 仍然是：

```text
GMR Retargeted ForehandClear MyoFullBody trajectory
    -> GoalTrajMimic lookahead observation
    -> PPO body imitation teacher policy
```

这个 teacher 作为蒸馏源是合理的。

---

### 2.2 StudentObservationFilterWrapper 的设计方向正确

`musclemimic/distill/obs_filter.py` 中的核心设计是：

```text
student observation = all non-goal observations + final goal element
```

其中 final goal element 被假定为 `GoalTrajMimic(enable_motion_phase=True)` 下的 motion phase。

这与我们之前推荐的第一版 student 设计一致：

```text
Teacher input:
  joint + muscle + foot contact + full goal lookahead

Student v1 input:
  joint + muscle + foot contact + motion phase
```

这比完全移除所有 goal 信息更稳，因为 ForehandClear 是长时序动作，student 需要知道当前动作相位，避免引拍、挥拍、随挥阶段混淆。

当前实现中的优点：

1. `build_student_obs_indices()` 会读取环境的 `goal` observation group。
2. 默认保留 `goal_indices[-1]` 作为 phase。
3. `StudentObservationFilterWrapper` 只过滤返回给 policy 的 observation，不改变底层 env state / reward / trajectory handler。
4. `obs_container` 被重新构造为：

```text
state: filtered state indices
phase / goal: one scalar phase index
```

这个设计是合理的。

---

### 2.3 wrapper 接入顺序基本正确

`musclemimic/algorithms/common/env_utils.py` 中当前顺序是：

```python
student_cfg = config.get("student_obs_filter", {})
if student_cfg.get("enabled", False):
    env = StudentObservationFilterWrapper(env, student_cfg)

if "len_obs_history" in config and config.len_obs_history > 1:
    split_goal = config.get("split_goal", False)
    env = NStepWrapper(env, config.len_obs_history, split_goal=split_goal)
```

这个顺序很重要。它意味着：

```text
先把 teacher full obs 过滤成 student obs
再对 student state 做 history stacking
```

如果 `split_goal=True`，则 `NStepWrapper` 会只 stack state history，而保留当前 phase；这正好符合 student policy 的需求。

推荐保持这个顺序。

---

### 2.4 PPO 网络创建中考虑了 student obs filter

`PPOJax._create_network()` 中已经增加了类似逻辑：

```python
if exp.get("student_obs_filter", {}).get("enabled", False):
    env = StudentObservationFilterWrapper(env, exp.student_obs_filter)
```

这个设计用于让 `ActorCritic` 初始化时看到正确的 `observation_space.shape`。这点很关键，因为 student policy 的 observation dim 已经不是 teacher 的 2418-D full obs，而是过滤后的 student obs。

同时，`wrap_env()` 也会在实际训练 rollout 时使用同样的 `StudentObservationFilterWrapper`。因此总体思路是正确的。

但建议后面加一个真实环境 smoke test，验证：

```text
agent_conf.network input dim == env.reset() 返回的 obs dim
```

尤其是在 `student_obs_filter.enabled=true + len_obs_history>1 + split_goal=true` 时。

## 3. 当前没有满足的部分

### 3.1 缺少 teacher rollout dataset collector

当前虽然有 `write_distill_shard()`，但还缺少真正的 teacher rollout 数据采集脚本。

需要新增一个脚本，例如：

```text
BadmintonMimic/scripts/collect_forehand_clear_distill_dataset.py
```

或者：

```text
scripts/collect_distill_dataset.py
```

它应该完成：

```text
输入：
  teacher checkpoint
  teacher config / motion path
  output dataset dir
  num_envs
  num_steps / num_episodes
  deterministic teacher action or stochastic teacher action

输出：
  shard_000000.npz
  shard_000001.npz
  ...
  metadata.json
```

每个 sample 至少保存：

```text
student_obs              # filtered obs: state + phase
teacher_action           # 建议 teacher actor mean，而不是 stochastic sample
teacher_action_sample    # 可选
teacher_log_std          # 可选，用于 KL distillation
teacher_value            # 可选，用于诊断或初始化 critic
reward                   # 可选

traj_no                  # 推荐
subtraj_step_no          # 推荐
phase                    # 推荐
raw_obs 或 raw_goal       # 可选调试字段
```

推荐默认 target 使用 teacher actor mean：

```text
teacher_action = pi_teacher.mean()
```

不要默认使用 stochastic sample，否则 BC target 噪声会变大。

---

### 3.2 缺少 BC/KD student trainer

当前有 dataset loader，但没有发现完整的 student 行为克隆 / 分布蒸馏训练器。

需要新增脚本，例如：

```text
BadmintonMimic/scripts/train_student_bc.py
```

或：

```text
musclemimic/distill/train_bc.py
```

它应该支持两种 loss：

#### 动作均值 MSE，第一优先级

```math
L_{BC} = \mathbb{E}\left[\|\mu_S(o^S_t) - a^T_t\|^2\right]
```

其中：

```text
o^S_t = student_obs
 a^T_t = teacher actor mean
```

#### KL distillation，第二优先级

```math
L_{KD} = D_{KL}(\pi_T(\cdot|o^T_t) || \pi_S(\cdot|o^S_t))
```

如果 dataset 保存了 teacher mean / std，则可以做 diagonal Gaussian KL。

训练器还需要：

1. 构建 student `ActorCritic`；
2. 使用 `student_obs_filter.enabled=true` 的 env/config 来确定 observation dim；
3. 支持从 teacher/student config 创建 checkpoint；
4. 保存成 PPO 能 resume / evaluate 的 checkpoint 格式；
5. 保存 train loss / val loss 曲线；
6. 保存 metadata：teacher checkpoint、student obs dim、action dim、dataset path、loss type。

### 3.3 缺少 no-lookahead student PPO fine-tune 配置

当前还需要一个明确的 student PPO fine-tune config，例如：

```text
fullbody/config_specific_task/conf_fullbody_badminton_student_gmr.yaml
```

建议内容：

```yaml
# @package _global_

defaults:
  - /fullbody/config_specific_task/conf_fullbody_badminton_gmr
  - _self_

wandb:
  tags: ["fullbody", "gmr", "badminton", "student", "no_future_lookahead"]
```

关键原则：

```text

```

也就是说，不要改掉 reference trajectory，也不要改掉 MimicReward。student 不看未来 goal，不等于训练时不能用 reference trajectory 作为 reward 监督。

### 3.4 缺少 on-policy / DAgger-style correction

只做 off-policy BC/KD 容易出现 distribution shift：

```text
teacher rollout states != student rollout states
```

因此，完整方案中还应该有 DAgger-style 数据聚合阶段：

```text
1. 用 BC student 初始化
2. student 自己 rollout
3. 在 student 访问到的状态上构造 teacher_obs
4. teacher relabel 得到 teacher_action
5. 追加写入新的 distill shards
6. 继续 BC/KD
```

建议新增脚本：

```text
BadmintonMimic/scripts/dagger_collect_student_states.py
```

或者统一为：

```text
scripts/collect_distill_dataset.py --policy-source student --labeler teacher
```

至少支持：

```text
--student-checkpoint
--teacher-checkpoint
--mix-teacher-action-prob
--max-early-termination-rate
--append-to-dataset
```

第一版可以简单一些：

```text
student rollout -> teacher relabel -> append dataset -> retrain student
```

不必一开始就实现复杂在线交替优化。

## 4. 当前实现中需要特别注意的风险点

### 4.1 `phase_index = goal_indices[-1]` 的假设需要强校验

当前 `StudentObservationFilterWrapper` 默认把 `goal_indices[-1]` 当成 motion phase。

这个在当前 `GoalTrajMimic(enable_motion_phase=True)` 中是合理的，因为 motion phase 是在 goal 末尾 append 的。

但建议增加真实环境测试，确认：

```text
phase index 确实是 normalized subtraj_step_no / trajectory_length
phase 值范围在 [0, 1]
```

建议新增测试：

```text
tests/integration/test_student_filter_myofullbody_goal_phase.py
```

测试内容：

```text
1. 构建 MjxMyoFullBody + GoalTrajMimic
2. reset 后读取 full goal obs
3. 检查 goal 最后一维随 subtraj_step 单调增加
4. 检查 StudentObservationFilterWrapper 输出最后一维等于 full goal 最后一维
```

---

### 4.2 不能直接用 teacher checkpoint 初始化 student PPO

teacher checkpoint 的 network input dim 是 full teacher observation；student 的 input dim 是 filtered observation。二者通常不兼容。

因此 student PPO fine-tune 应从以下 checkpoint 初始化：

```text
student BC checkpoint
```

而不是：

```text
teacher PPO checkpoint
```

如果想迁移 teacher 权重，需要实现显式的 network surgery，例如：

```text
1. 只迁移 action head / hidden layers 中维度兼容部分
2. 重新初始化第一层输入投影
3. 或者使用 adapter 把 student obs 投影到 teacher obs embedding
```

第一版不建议这么做。直接 BC 训练 student checkpoint 更稳。

---

### 4.3 BC checkpoint 必须能被 PPOJax / fullbody/eval.py 读取

BC trainer 不能只保存一个普通 `.npz` 参数文件。它应该保存为当前 PPO checkpoint/eval 系统能读取的格式，至少包含：

```text
params
run_stats
config
network definition metadata
```

否则后续 `fullbody/eval.py` 和 PPO fine-tune 会无法直接 resume/evaluate。

---

### 4.4 dataset 中最好保存 teacher action mean，而不是 sample

当前 PPO teacher 的 actor 是 Gaussian policy。采样动作有噪声，而 student BC 更适合拟合 teacher 的 mean action。

建议字段：

```text
teacher_action        # 默认 = teacher mean
teacher_action_sample # 可选 = teacher sampled action
teacher_log_std       # 可选
```

如果为了兼容已有 `REQUIRED_FIELDS = ("student_obs", "teacher_action")`，则保持 `teacher_action` 为 teacher mean。

---

### 4.5 对 student critic 的处理需要明确

BC 阶段主要训练 actor，但 checkpoint 里仍然需要 critic。

可选方案：

```text
方案 A：critic 随机初始化，PPO fine-tune 时重新学习
方案 B：用 dataset 中 teacher_value 监督 student critic
方案 C：BC 阶段只训练 actor，critic loss weight = 0
```

推荐第一版使用：

```text
actor: BC/KD 训练
critic: 可随机初始化，PPO fine-tune 时学习
```

如果 dataset 已保存 `teacher_value`，可以加一个较小权重的 value regression，但不是必须。
