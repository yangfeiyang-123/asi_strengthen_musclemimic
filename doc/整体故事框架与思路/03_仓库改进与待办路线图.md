# 仓库改进与待办路线图

> 仓库：`yangfeiyang-123/asi_strengthen_musclemimic`
> 目标：把当前大量代码能力收敛成一条 **Simple and Effective**、可训练、可验证、可写论文的三阶段主线。
> 推荐主方法：
> **Full-354 physiological tracking teacher → reference-free PEASD latent skill → LAB-based hitting**
>
> 本文严格区分：
>
> 1. 默认主分支已经存在的能力；
> 2. PR #1 分支已经实现但尚未形成正式实验结论的能力；
> 3. 仍需要新增或完成的工作。

---

## 0. 最重要的总体判断

当前仓库的问题已经不是“功能不够多”，而是：

$$
\boxed{
\text{功能过多、主线不够收敛、正式证据不足}
}
$$

PR 分支已经包含：

- full-354、fixed synergy、synergy residual；
- NMF、Graph-NMF、rank selection；
- 354 通道 taxonomy；
- fascicle continuity；
- EMG 采集、预处理、导入、映射和评估；
- direct distillation 和 latent decoder；
- Stage 3 LAB、右臂 residual、多个 reward 版本；
- 大量 YAML 和测试。

但当前仍缺少真正支撑论文结论的核心闭环：

1. 正式可用、事件对齐的真实 EMG；
2. 经过人工核验、允许训练的 EMG mapping；
3. 多 seed 的 PEASD tracking teacher；
4. EMG privileged latent distillation；
5. prior-only reference-free 闭环结果；
6. 物理可达且能稳定过网的 Stage 3；
7. 简洁、可解释的消融矩阵。

因此下一步不应继续增加更多 synergy 类型或 Stage 3 reward 版本，而应完成：

$$
\boxed{
\text{数据证据}
\rightarrow
\text{最小方法实现}
\rightarrow
\text{三阶段训练}
\rightarrow
\text{消融验证}
}
$$

## 3. 当前仍不能声称完成的事项

### 3.1 EMG 正式证据仍不完整

当前 PR 文档明确指出：

- 现有候选 trial 缺少独立证据绑定的 `racket_contact`；
- official eligible impact-aligned trial 数为 0；
- 16→15 mapping 仍是 provisional；
- 当前数据不能支持正式 paired timing/H correlation；
- 现有真人和 Stage 3 rollout 不是同一 reference trial。

因此目前 EMG 只能用于：

- 数据质量研究；
- 探索性 NMF；
- mapping 和 evaluator 测试；
- 方法开发。

不能直接作为正式训练 reward 或论文人体效度结论。

### 3.2 Privileged EMG latent distillation 尚未实现

当前 `PosteriorEncoder` 仍是：

$$
q(z\mid state,reference).
$$

`LatentTrainConfig` 支持 physical excitation、direct/fixed/residual decoder，但没有：

- `emg_context`；
- `emg_synergy_mean`；
- `emg_synergy_scale`；
- `emg_synergy_valid`；
- `SynergyHead`；
- EMG context dropout；
- uncertainty-aware latent synergy loss。

这正是 PEASD 的关键新增点。

### 3.3 Stage 3 尚未形成有效回球

当前最好的诊断证据仍表现为：

- 可以偶尔接触；
- 过网为 0；
- 出球竖直速度仍为负；
- 单独腕部控制不足；
- v30 没有正式 checkpoint。

所以 Stage 3 当前是“控制可达性研究阶段”，不能写成已经完成 adaptive hitting。

### 3.4 PR 规模过大

PR 改动超过 300 个文件，混合了：

- forehand clear；
- ChinaJump；
- continuity；
- Graph-NMF；
- EMG；
- Stage 3 多版本实验；
- 129 个 YAML；
- 大量测试和文档。

这会带来：

- 难以审查；
- 主方法难以冻结；
- 训练配置容易混淆；
- 论文结果和工程支线难以对应；
- Codex 后续修改容易继续扩散。

- M-channel synergy consistency；

- curriculum；

### 4.3 Privileged latent synergy distillation

在现有 latent trainer 上增加：

- EMG synergy context；
- synergy head；
- uncertainty loss；
- context dropout；
- checkpoint provenance。

### 4.4 LAB-based Stage 3

冻结：

- prior；
- decoder；
- grip provider。

只训练：

- high-level latent PPO；
- 必要时极小的、分组独立的右臂 bounded residual。

## 14. 修改 `musclemimic/latent_muscle/networks.py`

### 14.1 PosteriorEncoder

改为可选 context：

```python
class PosteriorEncoder(nn.Module):
    ...
    def __call__(self, state, reference_features, emg_context=None):
        pieces = [state, reference_features]
        if emg_context is not None:
            pieces.append(emg_context)
        x = jnp.concatenate(pieces, axis=-1)
        ...
```

要求：

- `emg_context=None` 时与旧路径兼容；
- checkpoint schema 明确是否启用；
- 不允许运行时误把 context 传给 prior。

### 14.2 SynergyHead

```python
class SynergyHead(nn.Module):
    synergy_dim: int

    @nn.compact
    def __call__(self, latent):
        return nn.softplus(
            nn.Dense(self.synergy_dim, name="synergy")(latent)
        )
```

第一版只用一层，保持 simple。

## 15. 修改 `musclemimic/latent_muscle/train_latent.py`

新增配置：

```yaml
emg_privileged:

emg_context = concatenate(
    batch["emg_synergy_mean"],

emg_context = modality_dropout(
    emg_context,
    p=config.context_dropout,
)

post_mu, post_raw_sigma = posterior(
    state,
    reference,
    emg_context,
)

z = reparameterize(...)
pred_action = decoder(state, z)
pred_synergy = synergy_head(z)

loss = action_loss(...)
loss += beta_kl * kl(...)
loss += lambda_h * tube_loss(
    pred_synergy,
    batch["emg_synergy_mean"],
    batch["emg_synergy_scale"],
    batch["emg_synergy_valid"],
)
```

新增监控：

- synergy head loss；
- per-dim correlation；
- context dropout fraction；
- shuffled-context loss；
- posterior change with/without context；
- prior/posterior gap；

## 18. 修改 Stage 3 action composition

当前诊断表明统一放大 residual scale 会同时放大继承动作。

推荐显式分离：

$$
a_{\mathrm{final}}
=
\operatorname{clip}
(
a_{\mathrm{decoder}}
+
\alpha_wR_w\tanh\rho_w
+
\alpha_eR_e\tanh\rho_e
+
\alpha_sR_s\tanh\rho_s,
-1,1
).
$$

其中：

- wrist；
- elbow/forearm；
- shoulder；

分别拥有：

- 独立 actuator name list；
- 独立 alpha；
- 独立 std；
- 独立 regularizer；
- 零初始化。

不得让继承动作和新增 correction 共用一个物理 scale。

## 28. Leave-channel-out

这是回答“少量 EMG 是否真的有迁移信息”的关键实验。

在 M 个通道中隐藏：

- 1；
- 2；
- 4；
- 或一组功能相关通道。

只用剩余通道构建 prior，再用隐藏通道进行后验验证。

它不能证明另外 339 个未测肌肉正确，但能说明：

> 部分 EMG 协同是否包含可推广到未直接监督肌肉观测的结构信息。
